# أوراد برهانية — Awrad (Flutter)

إعادة تصميم كاملة لتطبيق **كتاب الأوراد البرهانية** (الطريقة البرهانية الدسوقية الشاذلية)
بتقنية **Flutter** — كود واحد لأندرويد و iOS، بهوية بصرية مستوحاة من اللوجو
(أخضر زمردي + ذهبي) وطابع إسلامي زخرفي.

## الهوية البصرية
الألوان مأخوذة مباشرةً من اللوجو:
- أخضر زمردي ساطع `#009746`
- أخضر غامق `#207A46`
- أصفر ذهبي للقلب `#FEED00` (مُلطّف إلى ذهبي أنيق `#E6C463`)

خلفية خضراء غامقة فخمة + نصوص كريمية دافئة + لمسات ذهبية وفواصل زخرفية (۞).

## المميزات
- قارئ PDF كامل (١٣٧ صفحة) مع تكبير/تصغير باللمس ونقرة مزدوجة وسحب.
- تقليب صفحات RTL سلس.
- فهرس جانبي بالأقسام مع شريط تقدّم لكل قسم + بحث محلي.
- إشارات مرجعية (حفظ/حذف) تُخزّن محليًا.
- بحث في الأوراد، والانتقال السريع لرقم صفحة.
- استئناف من آخر صفحة تمت قراءتها.
- وضع ملء الشاشة، وأرقام عربية (٠١٢…)، وتأكيد قبل الخروج.

## البنية
```
lib/
  main.dart                 نقطة الدخول، RTL، الثيم، Provider
  theme/                    الألوان + الثيم + الخطوط (Cairo / Amiri)
  data/                     نماذج البيانات + فهرس الكتاب
  services/                 التخزين المحلي (shared_preferences)
  state/                    BookController (ChangeNotifier)
  utils/                    أدوات (الأرقام العربية)
  widgets/                  المكوّنات (اللوجو، الزخرفة، الهيدر، الفهرس، الحوارات…)
  screens/                  Splash / Reader / صفحة الكتاب
assets/
  pdf/book.pdf              الكتاب
  images/logo.png           اللوجو
  fonts/                    Cairo (الواجهة) + Amiri (النص القرآني)
```

## التشغيل
```bash
flutter pub get
dart run flutter_launcher_icons   # توليد أيقونة التطبيق من اللوجو
flutter run                       # تشغيل على جهاز/محاكي
flutter build apk --release       # بناء أندرويد
flutter build ios --release       # بناء iOS (يتطلب macOS + Xcode)
```

## الحزم المستخدمة
- `pdfrx` — عرض الـ PDF (مبني على PDFium، يدعم أندرويد/iOS/ويب).
- `provider` — إدارة الحالة.
- `shared_preferences` — حفظ الإعدادات والإشارات المرجعية.
- `flutter_launcher_icons` — توليد الأيقونات.
